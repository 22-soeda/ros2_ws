破線が T ポーズ（servo_home.yaml の原点の姿勢）。 各 ID の原点はこの姿勢でのサーボ値として取ってあるので、脚をまっすぐ真上に伸ばすと 実線が破線に重なり、上の「T ポーズからのずれ」が全部 0 になる。重ならなければ 原点か ID の対応がずれている。
